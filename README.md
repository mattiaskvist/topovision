## About the Project

**TopoVision** is a completed research prototype developed by the **KTH AI Society** in collaboration with **ReGen Villages**. The project serves as a proof-of-concept for how 3D models of landscapes can be procedurally built from standard 2D topographical maps using computer vision and deep learning.

By automating the conversion of 2D contour maps into 3D terrain assets, TopoVision demonstrates the potential to accelerate spatial planning, architectural visualization, and game development workflows.

## Project Status

This project has reached its conclusion. It successfully validates our core concepts and provides a strong foundation for future exploration, though it is engineered as a research prototype rather than a production-ready application.

**What we accomplished:**

- **Synthetic Data Pipeline**: Procedural generation of synthetic maps using Perlin noise and DEMs, complete with masks and COCO annotations.
- **Contour Segmentation**: A fully functioning training pipeline and U-Net model for isolating contour lines from map images.
- **3D Height Extraction**: An end-to-end prototype pipeline that pairs OCR (for reading elevation markers) with U-Net (for segmenting contours) to generate and export 3D meshes.

**Known Limitations (The "Prototype" Reality):**

- OCR-to-contour matching and height inference on complex, highly degraded real-world scans can occasionally be brittle.
- There is expected performance variability across different cartographic styles, as the models were trained on specific synthetic distributions and a limited subset of real-world tiles.
- Only supports 512x512 images.
- Details like roads, railways, and other map features can be incorrectly interpreted as contour lines, which can lead to incorrect height inference.

## How It Works

The TopoVision pipeline processes an input topographical map through a series of stages to construct a 3D terrain model:

1. **Image Input:** The pipeline takes a 2D topographical map image as its starting point.
2. **Text Detection (OCR):** The image is first passed to an OCR engine powered by EasyOCR, which reads the elevation text and outputs detection boxes for the numbers.
3. **Contour Extraction:** The image is then passed to a trained U-Net model, which segments and extracts the contour lines from the map.
4. **Skeletonization & Instance Detection:** We then use an algorithm that skeletonizes the segmented mask and identifies distinct instances of the individual contour lines.
5. **Elevation Association:** We combine the OCR detections with the individual contours using Hungarian matching to assign the correct elevation heights to the lines.
6. **3D Reconstruction:** Finally, we take the contours with their assigned heights and recreate the 3D model from that, inferring the heights and distances for missing contours to yield a continuous 3D mesh.

## Quickstart

This project uses `uv` for dependency management. To set up the environment:

```bash
uv sync
```

### End-to-End Demo

Want to see it in action? Run the provided demo script to process a sample tile.

```bash
uv run python tools/run_demo.py --device mps --image /path/to/your/image.png
```

**What the demo does:**

1. Downloads default U-Net weights from Hugging Face if needed.
2. Runs EasyOCR and the segmenting U-Net model over a sample map tile.
3. Automatically infers elevation data and generates a 3D terrain representation.
4. Writes outputs to `output/demo/`:
   - `*_predicted_mask.png`
   - `*_result.png`
   - `*_mesh.obj`

- Optional: add `--render-mesh` to open the 3D viewer.

The demo defaults to tiles generated by `process_data` under `data/training/`.
If you need to regenerate them, see the [GIS Tile Generation](#gis-tile-generation-process_data) section below.

## GIS Tile Generation (process_data)

The main data pipeline renders map tiles and masks from GIS contour sources:

Data is available from [OpenDEM SRTM Download](https://www.opendem.info/srtm_download_contours/)

```bash
uv run python src/data_pipeline/process_data.py \
  --input data/N60E013/N60E013.shp \
  --output data/training
```

_(Tiles are written to `data/training/<tile_name>/`)_

### Synthetic Data Generation

Generate synthetic contour maps with rotated text annotations for OCR and segmentation training:

```bash
uv run python src/data_pipeline/perlin_noise_generator.py
```

_(Outputs include images, masks, debug images, and COCO annotations saved to `data/synthetic/perlin_noise`)_

### Model Training

Training instructions and workflows (including local and Modal GPU execution) live in `src/training/README.md`.
